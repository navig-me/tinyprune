# Security policy

TinyPrune moves files to the macOS Trash on a schedule, so safety bugs matter. Report anything that could trash an item it should not (for example a Keep, protected-descendant, stale-identity or pause bypass), or any weakness in the update path.

Please use [GitHub private vulnerability reporting](https://github.com/navig-me/tinyprune/security/advisories/new) rather than a public issue. Include the TinyPrune version (`tinyprune --version` or the app's About box), macOS version and steps to reproduce.

Only the latest release is supported.
