TinyPrune

Give your files an expiry date.

TinyPrune is a Mac app that moves old files to the Trash after a time you choose. Downloads after two weeks, screenshots after one, node_modules once a project has sat untouched for a month. Nothing is deleted for good.

Install

  1. Get the app. Download TinyPrune.dmg from GitHub Releases and drag it to Applications. With Homebrew: brew install --cask tinyprune/tap/tinyprune
  2. Open it once by hand. Early builds are not notarized, so macOS blocks the first launch. Open System Settings, go to Privacy & Security, find the message about TinyPrune and click Open Anyway.
  3. Allow the background agent. TinyPrune offers to install it and sends you to Login Items to approve it. The agent does the actual work, so the app can stay closed.
  4. Add a folder. Pick Downloads or a template. New rules start in Preview, which lists what would be removed and moves nothing.

The first release is not out yet. Until then, build it yourself with the Xcode command line tools: git clone https://github.com/navig-me/tinyprune && cd tinyprune && swift Scripts/package-app.swift && open .build/package/TinyPrune.app

How it works

A rule is a folder, a match, and a wait.

Say which folder, what to match (a name, a pattern like *.dmg, a folder called build) and how long to wait. For code projects it can wait until the whole project has been idle, judged from file timestamps. It does not run git or open your files.

Every item says why.

Open any scheduled item to see the rule that matched, the date it expires, and what you can do about it: Keep it or add 7 or 30 days.

Keep

Keep beats every rule.

Mark a file Keep and nothing will touch it. A folder holding a kept file is not trashed either.

Trash

It goes to the Trash.

Items move to the regular macOS Trash, so you can put them back. TinyPrune has no permanent delete.

Rules you might write.

~/Downloads        *.dmg           7 days
~/Downloads        everything else 30 days
~/Desktop/Shots    screenshots     7 days
~/Developer/**     node_modules    30 days idle
~/Developer/**     .venv           45 days idle

Templates cover these. Each one creates normal rules you can edit or delete.

How rules work

It stays on your Mac.

No account, no network access, and it never reads what is inside your files.
